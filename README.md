# 5IN サービスLP

対話型の年間プログラム「5IN（ファイブ・イン）」のサービスLPです。1ファイルのHTMLで、写真は `assets/img/` にあります。

元は `yuki-kenma/Universal-Research-Laboratory` の `projects/5in-lp` で開発され、御社が今後own・運用するため、このリポジトリに複製しました（2026-11-03）。

## 配色

「Graphite & Magenta」を採用しています。色は `index.html` の `:root` にまとめて定義しています。

| 役割 | 色 |
|:--|:--|
| 地の濃い色（グラファイト） | `#1C1C1E` |
| 中間のグレー | `#76747A` |
| アクセント（ボタン・強調） | `#D9136F` |
| 背景（生成り） | `#F4F3F1` |

文字と背景の組み合わせは、いずれもコントラスト比4.5以上（WCAG AA）を確認しています。ロゴは元の色のままです。

## 手元で見る

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000/ を開きます。
